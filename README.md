# Districom · Inteligencia Comercial

Plataforma web de inteligencia comercial para una distribuidora de bebidas. Analiza datos de **AXUM** (preventa) y **STORE SYS** (facturación) para responder qué está pasando, dónde se pierden oportunidades y qué acción concreta tomar.

No reemplaza a AXUM ni a STORE SYS: es una capa de análisis.
